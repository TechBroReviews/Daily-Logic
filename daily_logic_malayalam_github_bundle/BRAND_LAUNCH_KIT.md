## 4. Step-by-Step Account Creation & Linking

### A. YouTube Channel Setup
1. [YouTube Studio](https://studio.youtube.com/) തുറന്ന് **Create Channel** ക്ലിക്ക് ചെയ്യുക.
2. **Customization** -> **Profile** വിഭാഗത്തിൽ:
   - പുതിയതായി തയ്യാറാക്കിയ **1:1 Profile Logo** (ബൾബ് + ഗിയർ + ഫാക്ട് ചെക്ക് ലെൻസ്), **16:9 Banner Image** എന്നിവ അപ്‌ലോഡ് ചെയ്യുക.
   - നിങ്ങൾ തിരഞ്ഞെടുത്ത പേരും മുകളിലെ **YouTube Channel Description**-ഉം ചേർക്കുക.
3. **Settings** -> **Channel** -> **Basic Info** വിഭാഗത്തിൽ ചാനൽ കീവേഡുകൾ നൽകുക: `Malayalam Fact Check, How Things Work Malayalam, Everyday Science Malayalam, Sathyam Lab, Malayalam Shorts`.
4. **Settings** -> **Upload Defaults** വിഭാഗത്തിൽ **Video Language** `Malayalam` എന്നും **Category** `Science & Technology` എന്നും സെറ്റ് ചെയ്യുക.

### B. Facebook Page & Instagram Professional Account Setup
1. **Facebook Page**: `facebook.com/pages/create` വഴി പേജ് തുടങ്ങി ലോഗോയും ബാനറും നൽകുക.
2. **Instagram Professional Account**: ഇൻസ്റ്റാഗ്രാം അക്കൗണ്ട് തുടങ്ങി **Settings** -> **Account type and tools** -> **Switch to professional account** വഴി **Creator** അക്കൗണ്ട് ആക്കുക.
3. **Link Accounts**: ഫേസ്ബുക്ക് പേജിന്റെ **Linked Accounts** -> **Instagram** വിഭാഗത്തിൽ ഇൻസ്റ്റാഗ്രാം അക്കൗണ്ട് ബന്ധിപ്പിക്കുക.

| Secret Name | Purpose |
| :--- | :--- |

| `FB_PAGE_ID` | നിങ്ങളുടെ Facebook Page ID |
